# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within MSF Commander, please send an email to **darkhackererror@gmail.com**. All security vulnerabilities will be promptly addressed.

**Please do NOT report security vulnerabilities through public GitHub issues.**

## Responsible Disclosure

We follow responsible disclosure practices:
- Allow reasonable time for fixes before public disclosure
- Credit reporters in release notes (unless anonymity requested)
- Work with reporters to understand and validate issues

## Scope

This security policy applies to:
- MSF Commander main repository
- Official releases and distributions

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Security Best Practices

When using MSF Commander:
- Always obtain proper authorization before testing
- Use only on systems you own or have permission to test
- Follow responsible disclosure guidelines
- Keep the tool updated to the latest version

---

**Thank you for helping keep MSF Commander and its users safe!**
